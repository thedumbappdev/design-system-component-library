Framework / Build Tool

The prompt specifies Tailwind CSS + Flowbite. Which framework should power the documentation site?

Next.js (Static Export)

App Router, MDX for docs pages, file-based routing, built-in image optimization, ISR capability for future dynamic content. Heavier but most scalable.

Pros
  • Rich ecosystem + docs
  • Easy MDX integration
  • Future-proof
Cons
  • Heavy for a docs site
  • Slower dev startup

Vite + React

Lightweight, fast HMR, React Router for navigation, MDX plugin. Less overhead than Next.js for a pure static site.

Pros
  • Fastest dev experience
  • Minimal boilerplate
  • Smaller bundle
Cons
  • Manual routing config
  • No built-in image opt

Astro

Content-collections for docs, zero JS by default, island architecture for interactive component previews. Best for content-heavy sites.

Pros
  • Fasteset static output
  • Built for content sites
  • Minimal JS shipped
Cons
  • React interop possible
  • Smaller ecosystem
