Component Page Template

Every component page follows the same structure — consistency is a design principle.

Page Structure (top to bottom)

1. Header
Component name (large), short description, status badge (Stable/Beta/Deprecated), breadcrumb
↓
2. Usage Guidelines
"Use when" / "Don't use when" — clear, opinionated guidance
↓
3. Visual Playground
Live interactive preview — toggle variants, states, sizes. See changes in real-time.
↓
4. Variants
Visual grid showing every variant (primary, secondary, outline, ghost, danger, etc.)
↓
5. States
Hover, focus, active, disabled, loading — each shown with code toggle
↓
6. Props Table
Prop name, type, default, description — auto-generated from types or manually defined
↓
7. Accessibility
Keyboard support, ARIA roles, focus management, contrast notes
↓
8. Code Snippets
Copyable implementation examples for each variant
↓
9. Related Components
Links to connected components (e.g. Button → Dropdown → Modal)
↓
10. Prev / Next Navigation
Navigate between components in sequence

Implementation

MDX
Documentation content as MDX files, React components as inline JSX
Preview
Live component instances rendered inside docs, controls via React state
Code
Syntax-highlighted code blocks with copy button
